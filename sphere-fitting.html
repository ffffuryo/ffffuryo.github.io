STEP 1

何がしたいの？ ― スマホのコンパスの話

スマホには、地球の磁気（地磁気）を測る磁気センサが入っています。センサは磁気の向きと強さを $(x,\,y,\,z)$ の3つの数値で出力します。

地磁気の強さはその場所でほぼ一定です。だから、スマホをいろいろな向きに回しながら測ると、測定値の点は半径が一定の球面の上に並びます。

理想的には、その球の中心は原点 $(0,0,0)$ のはずです。ところが実際は、スマホ内部のスピーカーや金属部品が出す磁気のせいで、球の中心が原点からずれます。このずれを「オフセット」と呼びます。

やりたいこと

測定した点の集まりから球の中心（＝オフセット）と半径を求めます。オフセットがわかれば、測定値から引き算して正しい方位を出せます。

体験：磁気センサの測定データ（3D）

ドラッグで回転できます。灰色の十字が原点、赤が推定した球の中心です。スライダーでオフセットや測定誤差を変えてみましょう。

ノイズがあっても、点がたくさんあれば中心をかなり正確に当てられることがわかります。「机の上で水平に回すだけ」を選ぶとどうなるかは、STEP 9 で考えます。

STEP 2

球の方程式

数学IIで習った円の方程式を思い出しましょう。中心 $(a,\,b)$、半径 $r$ の円は次の式で表されます。

$$(x-a)^2 + (y-b)^2 = r^2$$

これは「点 $(x,y)$ と中心の距離が $r$ である」という意味でした（三平方の定理）。3次元でも同じように考えると、中心 $(x_0,\,y_0,\,z_0)$、半径 $r$ の球面は次の式になります。

$$(x-x_0)^2 + (y-y_0)^2 + (z-z_0)^2 = r^2$$

求めたい未知数は $x_0,\ y_0,\ z_0,\ r$ の4つです。

考えてみよう：中心 $(1,\,-2,\,3)$、半径 $2$ の球の方程式は？

$(x-1)^2 + (y+2)^2 + (z-3)^2 = 4$ です。$y-(-2)=y+2$ になる点と、右辺が $r^2=4$ になる点に注意しましょう。

STEP 3

「ズレ」を数で表す ― 最小二乗法の考え方

測定した点を $(x_1,y_1,z_1),\ (x_2,y_2,z_2),\ \dots,\ (x_n,y_n,z_n)$ とします（全部で $n$ 個）。$k$ 番目の点を球の方程式の左辺に入れて、右辺の $r^2$ を引いた値を $e_k$ とします。

$$e_k = (x_k-x_0)^2 + (y_k-y_0)^2 + (z_k-z_0)^2 - r^2$$
点の位置$e_k$ の値
ちょうど球面の上$0$
球の外側プラス
球の内側マイナス

$e_k$ は「その点が球からどれだけずれているか」を表す数です。でも、ただ足し合わせるとプラスとマイナスが打ち消し合ってしまいます。そこで2乗してから全部足します。

$$J = \sum_{k=1}^{n} e_k^{\,2} = \sum_{k=1}^{n} \Bigl\{(x_k-x_0)^2 + (y_k-y_0)^2 + (z_k-z_0)^2 - r^2\Bigr\}^2$$
最小二乗法

この $J$（目的関数といいます）がいちばん小さくなる $x_0,\,y_0,\,z_0,\,r$ を「いちばんよく合う球」とします。「2乗の和を最小にする」ので最小二乗法といいます。

$\Sigma$（シグマ）記号の復習

$\displaystyle\sum_{k=1}^{n} a_k = a_1 + a_2 + \cdots + a_n$ です（数学B「数列」）。以下では範囲を省略して $\Sigma a_k$ と書くことがあります。

体験：自分の手で $J$ を最小にしてみよう（2次元版＝円）

球は3次元で見にくいので、まず2次元の「円」で試します。考え方はまったく同じです。スライダーで円を動かして、$J$ をできるだけ小さくしてみましょう。キャンバスをクリックすると点を追加できます。

円の外側にある点のズレ（$e_k>0$） 円の内側にある点のズレ（$e_k<0$） 最小二乗法の答え（「答えを見る」で表示）

手で動かすと、3つのスライダーを行ったり来たりしてなかなか最小にたどり着けません。そこで、計算で一発で答えを出す方法をこれから学びます。

STEP 4

式を変形する ― この方法のいちばんの工夫

$J$ の中身の括弧を展開します。たとえば $(x_k-x_0)^2 = x_k^2 - 2x_0x_k + x_0^2$ です。$y,\,z$ も同じように展開して並べ替えると、次のようになります。

$$J = \sum \Bigl\{ x_k^2+y_k^2+z_k^2 - 2x_0\,x_k - 2y_0\,y_k - 2z_0\,z_k + \bigl(x_0^2+y_0^2+z_0^2-r^2\bigr) \Bigr\}^2$$

ここで、未知数のかたまりを新しい文字に置き換えます。

$$X_0 = 2x_0,\qquad Y_0 = 2y_0,\qquad Z_0 = 2z_0,\qquad R = r^2 - x_0^2 - y_0^2 - z_0^2$$

すると、式がすっきりします。

$$J = \sum \Bigl\{ \underbrace{x_k^2+y_k^2+z_k^2}_{\text{データから計算できる数}} - X_0\,x_k - Y_0\,y_k - Z_0\,z_k - R \Bigr\}^2$$
なぜ置き換えると嬉しいのか

新しい未知数 $R,\ X_0,\ Y_0,\ Z_0$ は、括弧の中に1次式（2乗や未知数どうしの掛け算がない形）で入っています。このおかげで、次のステップで出てくる方程式がただの連立1次方程式になり、必ず計算で解けるようになります。

高校数学とのつながり

$x^4 - 5x^2 + 4 = 0$ を $t = x^2$ とおいて2次方程式にするのと同じ「置き換え」の発想です。難しい形を、知っている形に変えるのがコツです。

考えてみよう：$R,\,X_0,\,Y_0,\,Z_0$ が求まったら、元の中心と半径はどう戻す？

$x_0 = \tfrac12 X_0,\ y_0 = \tfrac12 Y_0,\ z_0 = \tfrac12 Z_0$ です。半径は $R = r^2 - x_0^2 - y_0^2 - z_0^2$ を $r$ について解いて、$r = \sqrt{R + x_0^2 + y_0^2 + z_0^2}$ となります。

STEP 5

いちばん小さい所では「微分が0」

1変数の場合の復習

$f(x) = (x-3)^2 + 1$ の最小値は $x=3$ のときです。グラフの谷底では接線が水平なので、$f'(x)=0$ になります。

実際、$f'(x) = 2(x-3)$ なので、$f'(x)=0$ を解くと $x=3$ が得られます。

変数が4つある場合：偏微分

$J$ は $R,\ X_0,\ Y_0,\ Z_0$ の4つの変数の関数です。谷底では、どの変数を動かしても傾きが0になっているはずです。

「ほかの変数は定数とみなして、1つの変数だけで微分する」ことを偏微分といい、$\dfrac{\partial J}{\partial R}$ のように書きます（$\partial$ は「ラウンド」や「デル」と読みます）。大学で習う記号ですが、やっていることは普通の微分と同じです。

$$\frac{\partial J}{\partial R} = \frac{\partial J}{\partial X_0} = \frac{\partial J}{\partial Y_0} = \frac{\partial J}{\partial Z_0} = 0$$

実際に微分してみる

括弧の中身をまとめて $e_k$ と書きます。

$$e_k = x_k^2+y_k^2+z_k^2 - X_0x_k - Y_0y_k - Z_0z_k - R,\qquad J = \sum e_k^{\,2}$$

合成関数の微分 $\bigl(e^2\bigr)' = 2e\cdot e'$ を使います（数学III）。

どの変数で微分？$e_k$ の微分結果（＝0とおく）
$R$$-1$$-2\,\Sigma\, e_k = 0$
$X_0$$-x_k$$-2\,\Sigma\, x_k e_k = 0$
$Y_0$$-y_k$$-2\,\Sigma\, y_k e_k = 0$
$Z_0$$-z_k$$-2\,\Sigma\, z_k e_k = 0$

たとえば1行目の $\Sigma e_k = 0$ を移項して整理すると、次の式になります（$R$ を $n$ 回足すので $\Sigma R = nR$）。

$$\Sigma(x_k^2+y_k^2+z_k^2) = n\,R + \bigl(\Sigma x_k\bigr) X_0 + \bigl(\Sigma y_k\bigr) Y_0 + \bigl(\Sigma z_k\bigr) Z_0$$
ここが大事

$\Sigma x_k$ や $\Sigma(x_k^2+y_k^2+z_k^2)$ は、測定データを足し算すれば求まる、ただの数です。だからこれは $R,\,X_0,\,Y_0,\,Z_0$ の1次方程式です。残り3つの式も同じ形になるので、未知数4つ・式4本の連立1次方程式ができあがります。

考えてみよう：2つ目の式（$X_0$ で微分したもの）を書き下すと？

$\Sigma x_k e_k = 0$ を整理すると、次のようになります。

$$\Sigma x_k(x_k^2+y_k^2+z_k^2) = \bigl(\Sigma x_k\bigr)R + \bigl(\Sigma x_k^2\bigr)X_0 + \bigl(\Sigma x_ky_k\bigr)Y_0 + \bigl(\Sigma x_kz_k\bigr)Z_0$$
STEP 6

行列で連立方程式をまとめる

行列って何？（はじめての人へ）

行列は「連立方程式の係数を表にしたもの」と考えればOKです。たとえば次の連立方程式があるとします。

$$\begin{cases} 2a + 3b = 8 \\ \phantom{2}a - \phantom{3}b = -1 \end{cases} \quad\Longleftrightarrow\quad \begin{pmatrix} 8 \\ -1 \end{pmatrix} = \begin{pmatrix} 2 & 3 \\ 1 & -1 \end{pmatrix}\begin{pmatrix} a \\ b \end{pmatrix}$$

右辺の計算ルールは「行列の横の行と縦のベクトルの、対応するもの同士を掛けて足す」です。1行目なら $2\times a + 3\times b$ になります。

球の場合の4本の式

STEP 5 の4本の式を、同じようにまとめると次のようになります。

$$ \underbrace{\begin{pmatrix} \Sigma (x_k^2+y_k^2+z_k^2) \\ \Sigma x_k (x_k^2+y_k^2+z_k^2) \\ \Sigma y_k (x_k^2+y_k^2+z_k^2) \\ \Sigma z_k (x_k^2+y_k^2+z_k^2) \end{pmatrix}}_{\vec b} = \underbrace{\begin{pmatrix} n & \Sigma x_k & \Sigma y_k & \Sigma z_k \\ \Sigma x_k & \Sigma x_k^2 & \Sigma x_k y_k & \Sigma x_k z_k \\ \Sigma y_k & \Sigma x_k y_k & \Sigma y_k^2 & \Sigma y_k z_k \\ \Sigma z_k & \Sigma x_k z_k & \Sigma y_k z_k & \Sigma z_k^2 \end{pmatrix}}_{A} \begin{pmatrix} R \\ X_0 \\ Y_0 \\ Z_0 \end{pmatrix} $$
気づいたかな？ ― 対称行列

行列 $A$ は、左上から右下への対角線で折り返すと同じ形になっています。このような行列を対称行列といいます。プログラムではこの性質を使って、計算を約半分に減らしています。

逆行列で解く

$3x = 6$ は両辺に $\tfrac13$ を掛けて解けます。行列でも同じで、$A$ の逆行列 $A^{-1}$（掛けると「1」にあたる単位行列になる行列）を両辺に掛ければ解けます。

$$\vec b = A\vec u \quad\Longrightarrow\quad \vec u = A^{-1}\vec b,\qquad \vec u = \begin{pmatrix} R \\ X_0 \\ Y_0 \\ Z_0 \end{pmatrix}$$

あとは STEP 4 の式で元に戻せば、球の中心と半径が求まります。

$$x_0 = \tfrac12 X_0,\quad y_0 = \tfrac12 Y_0,\quad z_0 = \tfrac12 Z_0,\quad r = \sqrt{R + x_0^2 + y_0^2 + z_0^2}$$
注意：逆行列はいつでもあるとは限らない

$0$ に逆数がないように、行列にも逆行列が存在しない場合があります。これがどんなときに起きるかは STEP 9 で扱います。

STEP 7

掃き出し法で逆行列を求める

元記事のプログラムは、掃き出し法（ガウス・ジョルダンの消去法）で逆行列を求めています。中身は、連立方程式の加減法（式を何倍かして引き、文字を消していく方法）を機械的にくり返すだけです。

  1. 行列 $A$ の右に、単位行列（対角線が1、ほかは0）を並べます。
  2. 左側の対角成分（黄色）が 1 になるように、その行全体を割ります。
  3. ほかの行から「その行の何倍か」を引いて、同じ列のほかの成分を 0 にします。
  4. これを全部の列でくり返すと、左側が単位行列になります。このとき右側が逆行列になっています。

体験：3×3 の対称行列で掃き出し法を1手ずつ見る

本物は 4×4 ですが、手順は同じです。「次へ」を押して進めましょう。分数で正確に計算しています。

左側：$A$ → 単位行列右側：単位行列 → $A^{-1}$
確かめてみよう：本当に逆行列になっている？

最後に右側に出てくる行列を $A$ に掛けてみると、単位行列になります。たとえば1行目どうしなら $2\cdot\tfrac34 + 1\cdot(-\tfrac14) + 1\cdot(-\tfrac14) = \tfrac{6-1-1}{4} = 1$ です。

STEP 8

C言語のプログラムを読む

元記事の関数 LSMSphere は、ライブラリを使わず素のC言語でここまでの計算をしています。流れは4つのステップです。

ステップやっていること対応する STEP
① データ数の確認点が4個未満なら失敗（-1）を返す。未知数が4つなので、式も最低4本（点が4個）必要。STEP 2
② 合計を集める全部の点をループして、$\Sigma x_k$ や $\Sigma x_k^2$ などを mat（行列 $A$）と vec（ベクトル $\vec b$）に足し込む。STEP 5・6

② 合計を集める部分

// 1点ずつ取り出して合計に足し込む
for (int i = 0; i < pointListNum; i++)
{
    double mx = pointList[i].x;
    double my = pointList[i].y;
    double mz = pointList[i].z;

    mat[0][0] += 1;          // n（点の個数）
    mat[0][1] += mx;         // Σx
    mat[0][2] += my;         // Σy
    mat[0][3] += mz;         // Σz
    mat[1][1] += (mx * mx);  // Σx²
    mat[1][2] += (mx * my);  // Σxy
    mat[1][3] += (mx * mz);  // Σxz
    mat[2][2] += (my * my);  // Σy²
    mat[2][3] += (my * mz);  // Σyz
    mat[3][3] += (mz * mz);  // Σz²

    double rho = (mx * mx) + (my * my) + (mz * mz);  // x²+y²+z²
    vec[0] += rho;           // Σ(x²+y²+z²)
    vec[1] += (rho * mx);    // Σx(x²+y²+z²)
    vec[2] += (rho * my);
    vec[3] += (rho * mz);
}
// 対称行列なので、左下半分は右上半分をコピーするだけ
mat[1][0] = mat[0][1];
mat[2][0] = mat[0][2];  mat[2][1] = mat[1][2];
mat[3][0] = mat[0][3];  mat[3][1] = mat[1][3];  mat[3][2] = mat[2][3];

行列の右上半分だけ計算して、最後にコピーしています。これが STEP 6 の「対称行列」の活用です。

③ 掃き出し法の部分

for (int i = 0; i < 4; i++)
{
    tmp = 1 / mat[i][i];               // 対角成分の逆数
    for (int j = 0; j < 4; j++)
    {
        mat[i][j]    *= tmp;           // i行目を割って、対角成分を1にする
        matinv[i][j] *= tmp;           // 右側（逆行列側）にも同じ操作
    }
    for (int j = 0; j < 4; j++)
    {
        if (i == j) continue;
        tmp = mat[j][i];               // j行目の、消したい成分
        for (int k = 0; k < 4; k++)
        {
            mat[j][k]    -= (mat[i][k] * tmp);     // i行目の tmp 倍を引く
            matinv[j][k] -= (matinv[i][k] * tmp);
        }
    }
}

STEP 7 のデモでやった操作が、そのままプログラムになっています。

④ 答えに戻す部分

*Radius = sqrt(R + (X0 * X0 + Y0 * Y0 + Z0 * Z0) / 4.0);   // ← 要注意（下を参照）
Answer->x = X0 / 2.0;
Answer->y = Y0 / 2.0;
Answer->z = Z0 / 2.0;

$X_0 = 2x_0$ なので $x_0^2 = X_0^2/4$ です。つまりこの行は $r=\sqrt{R+x_0^2+y_0^2+z_0^2}$ をそのまま計算しています。

コードの小さなミス
  • 関数の引数は double *radius（小文字）なのに、最後の行は *Radius（大文字）になっています。C言語は大文字と小文字を区別するので、このままではコンパイルエラーです。*radius に直すと動きます。
  • sqrt を使うには #include <math.h> が必要です。
STEP 9

注意点 ― うまくいかないのはどんなとき？

① 点が平面に偏っていると解けない

STEP 1 のデモで「机の上で水平に回すだけ」を選んでみましょう。点がほぼ同じ高さ（一つの平面の上）に集まり、推定がうまくいかなくなります。

理由を考えます。平面上の点だけでは、その点を通る球は無数にあります。大きい球の上の方を通る場合もあれば、小さい球の真ん中を通る場合もあり、どれか一つに決まりません。このとき行列 $A$ の逆行列が存在しなくなります。ノイズで少しだけ平面からずれていると、計算はできても結果が大きく狂います。

「8の字に回して」と言われるのは、点を球面全体に散らばらせて、この問題を避けるためでもあります。

② プログラムが0で割ってしまう可能性

元記事の掃き出し法は、対角成分 mat[i][i] が 0（またはほぼ0）になったときの対策をしていません。そうなると0で割ってしまいます。実用的なプログラムでは、絶対値の大きい行と入れ替える「ピボット選択」という工夫をよく使います（このページのデモではピボット選択をしています）。

③ 「ズレ」の測り方は近似

この方法で最小にしているのは、点と球面の本当の距離ではありません。最小にしているのは $e_k$（球の式に代入した値）です。中心からの距離を $d_k$ とすると $e_k = d_k^2 - r^2 = (d_k - r)(d_k + r)$ なので、$e_k$ は本当の距離のズレ $d_k - r$ のおよそ $2r$ 倍になります。

誤差が小さいうちはほぼ同じ答えになり、そのうえ連立1次方程式だけで確実に解けるのがこの方法の大きな利点です。本当の距離で最小化する方法もありますが、くり返し計算（反復法）が必要になります。
