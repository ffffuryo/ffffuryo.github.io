# スマホ単体版 手順書（スタンドアロン PWA）

PC サーバーも Tailscale も使わず、スマホのブラウザだけで FE Study を使うための手順です。学習記録はスマホ内に保存され、一度データを取得すればオフラインで動きます。

- 公開 URL: **https://ffffuryo.github.io/fe/**
- 仕様の詳細: [SPEC.md](SPEC.md) 7章

---

## 1. 公開（初回のみ）

1. このブランチ `claude/youthful-galileo-fhj79y` を GitHub Pages の公開ブランチ（通常 `main`）にマージする。
2. GitHub のリポジトリの **Settings → Pages** を開き、公開元のブランチ（と `/ (root)`）が正しいか確認する。
3. 数分待つ。その後 **https://ffffuryo.github.io/fe/** が開ければ公開完了。

---

## 2. スマホで初回セットアップ

1. スマホのブラウザで **https://ffffuryo.github.io/fe/** を開く。
2. 「**問題データをダウンロード（約 40MB・Wi-Fi 推奨）**」を 1 タップ。進捗バーが 100% になるまで待つ。
3. **ホーム画面に追加する**:
   - **iPhone（Safari）**: 画面下の共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**: メニュー（︙）→ 「ホーム画面に追加」または「アプリをインストール」

> **iPhone の注意**: ホーム画面に追加しない場合、7 日間使わないと保存データが消えることがあります。iPhone は必ずホーム画面に追加して使ってください。ホーム画面のアイコンから開くと、ブラウザのアドレスバーなしで起動します。

---

## 3. 書籍付録パック（任意・私的使用のみ）

科目B の書籍付録（翔泳社『出るとこだけ！基本情報技術者［科目B］第4版』付録）の解説・追加問題を読み込む手順です。

> **重要**: 付録由来のデータは**私的使用のみ**です。Web（GitHub Pages）やリポジトリ、共有フォルダの公開先には置かないでください。受け渡しは AirDrop・ファイル共有・自分だけのクラウドストレージなど、本人だけが見られる方法に限ってください。

1. PC で付録パックを作成する:
   ```bash
   cd fe-study
   python -m importer.kamoku_b --src <付録PDFのフォルダ>
   python -m tools.pack
   ```
   → `dist/fe-pack-private.zip` ができます。
2. `dist/fe-pack-private.zip` をスマホへ渡す（AirDrop / ファイル共有 / 自分だけのクラウドストレージ）。
3. スマホのアプリで **設定 → データ管理 →「書籍付録パックを読み込む」** を開き、zip を選ぶ。

---

## 4. 問題データの更新（PC で行う）

新しい問題を取り込んだときや、問題データを修正したときの手順です。

1. PC で取り込みを行う（必要なもののみ）。
2. パックとサイトを再生成する:
   ```bash
   python -m tools.pack && python -m tools.build_site
   ```
3. 変更をコミットして push する（`fe/` 以下が公開対象。private パックは含まれません。`tools.build_site` が混入を検査します）。
4. スマホで **設定 → データ管理 →「公開パックを更新」** を実行する。

> 学習記録は消えません。更新の反映に時間がかかる場合は、GitHub Pages の公開完了を数分待ってから実行してください。

---

## 5. バックアップと機種変更

学習記録（解答履歴・設定）はスマホ内にだけ保存されるため、定期的にバックアップしてください。

- **バックアップ**: 設定 → データ管理 →「**学習記録を書き出す**」（JSON ファイルが保存されます）。書き出したファイルは、クラウドストレージなどに保管してください。
- **機種変更・復元**: 新しい端末で https://ffffuryo.github.io/fe/ を開いて初回セットアップ（問題データのダウンロード・ホーム画面追加）を行い、設定 → データ管理 →「**学習記録を読み込む**」で JSON を選びます。
- 問題データはバックアップ不要です（公開パックから再取得できます）。書籍付録パックは PC 側の `dist/fe-pack-private.zip` から再読み込みしてください。

## 6. トラブルシュート

| 症状 | 確認すること・対処 |
|---|---|
| ページが開かない | GitHub Pages が未公開の可能性があります（1 の手順で公開元を確認し、数分待つ）。URL が `https://ffffuryo.github.io/fe/`（末尾の `/fe/`）になっているか確認してください。 |
| 「問題データをダウンロード」が止まる・失敗する | Wi-Fi が不安定な場合は、電波の良い場所で再試行してください。スマホの空き容量が数百 MB 以上あるか確認してください。途中で失敗した場合は、もう一度ボタンを押せば最初からやり直せます。 |
| 学習データが消えた | iPhone で 7 日間使わなかった場合に起こりえます。ホーム画面に追加して使うことで防げます。事前に書き出したバックアップ（JSON）があれば、設定 → データ管理 →「学習記録を読み込む」で復元できます。 |
| 問題データの更新が反映されない | アプリを一度完全に閉じて、開き直してください。それでも反映されない場合は、設定 → データ管理 →「公開パックを更新」を実行してください。アプリの更新（Service Worker）は、次回起動時に切り替わります。 |
| 書籍付録パックが読み込めない | zip が `dist/fe-pack-private.zip` そのものか確認してください（`tools.pack` を再実行して作り直す）。 |
| 画面が古いまま | ブラウザのキャッシュを消すか、ホーム画面のアイコンを一度削除して、ブラウザから開き直してホーム画面に追加し直してください。 |

---

## 7. 注意事項

- 問題データ（公開パック）は IPA の公開問題が元になっています。出典は各問題に表示されます。
- 書籍付録由来のデータは私的使用のみです。第三者への共有・公開はしないでください。
- サーバー版（PC + Tailscale）の手順は [DEPLOY_TAILSCALE.md](DEPLOY_TAILSCALE.md) を参照してください。
