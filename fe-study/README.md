# FE Study — 基本情報技術者試験 学習アプリ（科目A・科目B）

通学中にスマホで 5〜10 分ずつ解く、自分専用の FE（基本情報技術者試験）対策アプリです。科目A（多肢選択）と科目B（長文・プログラミング・情報セキュリティ）に対応しています。

## 使い方は2通り

### ①スマホ単体版（推奨）
**https://ffffuryo.github.io/fe/ を開くだけ**で使えます。PC サーバーも Tailscale も不要で、一度問題データをダウンロードすれば**オフラインで動きます**。学習記録はスマホの中（ブラウザの IndexedDB）に保存されます。
手順は [docs/STANDALONE.md](docs/STANDALONE.md) を参照してください。

### ②サーバー版
自宅 PC で Python（Flask）+ SQLite を動かし、Tailscale 経由でスマホから接続します。学習記録は PC 側の `data/fe.db` に保存されます。配備手順は [docs/DEPLOY_TAILSCALE.md](docs/DEPLOY_TAILSCALE.md) を参照してください。

> どちらを使っても問題・機能はほぼ同じです。迷ったら **①スマホ単体版**から始めてください。

## 特長
- **1 タップで学習開始**（科目A は既定 8 問 ≒ 8 分）。途中で閉じても「続きから」で再開。
- **科目B 対応**: 1 回 2 問 ≒ 10 分（1 問の目標 5 分）。擬似言語・情報セキュリティのテーマ選択が可能。
- **書籍付録の解説ビューア**: 科目B の解説画像を全画面で縦に表示（付録パックを読み込んだ場合のみ）。
- **オートセーブ**: 回答は即保存、経過時間も定期的に保存。電波が切れても回答は端末に溜めて復帰時に送信（サーバー版）。
- **解いた問題を記録**し、出題は「前回不正解 → 未出題（苦手分野優先）→ 時間がかかった問題 → 習得済み」の順に配分。
- **解答時間の記録と分析**: 平均・中央値・目標（90 秒）超過率、分野別平均時間、計算/非計算、時間帯別正答率、日別推移、遅かった問題。
- **分野別の成績一覧**: シラバス Ver.9.2 の 3 系統 23 中分類ごとに正答率・学習済数・平均時間。
- **科目B の成績**: テーマ（擬似言語 / 情報セキュリティ）別、タグ別（トレース・再帰・一次元配列 など）、難易度別の正答率と平均時間。
- **計算問題を含める/含めない** の設定（科目A）。
- **模擬試験**: 科目A・科目B とも公開問題の回を模試として実施。制限時間つき、終了まで正誤非表示。令和5〜8年度の公開問題は模試専用（学習モードには出ません）。
- 目に優しい配色（ライト/ダーク自動）、文字サイズ 4 段階、ホーム画面に追加可能。

- 付録由来のデータ（`dist/fe-pack-private.zip`、`data/`）は**リポジトリや Web（GitHub Pages）に置きません**。`.gitignore` 済みですが、念のため公開しないでください。
- `tools.build_site` は、付録由来の問題や private パックが `fe/` に混入していないかを検査し、見つかれば**ビルドを中止**します。
- アプリは個人利用（Tailscale 内、またはスマホ内）に限ってください。`tailscale funnel` など外部公開の手段は使わないでください。

## セットアップ（サーバー版）
```bash
bash scripts/setup.sh      # venv 作成・依存インストール・IPA から問題取り込み（初回 数分）
bash scripts/run.sh        # http://127.0.0.1:8000/
```
スマホからの利用は [docs/DEPLOY_TAILSCALE.md](docs/DEPLOY_TAILSCALE.md)（`tailscale serve --bg 8000`）。

科目A 問題画像の OCR 改善（任意）:
```bash
sudo apt-get install -y tesseract-ocr tesseract-ocr-jpn && python -m importer --offline
```
- 平成21年〜令和4年の PDF はスキャン画像のため、問題は「切り抜き画像 + ア〜エのボタン」で出題します。
- 画像問題は計算問題の判定ができないため、「計算問題を含めない」は文字データのある問題にのみ効きます。OCR を入れて取り込み直すと分類・計算判定が改善されます。

## 開発コマンド
```bash
python -m pytest -q tests          # Python テスト
node --test tests/js/              # スタンドアロン版（ブラウザ側ロジック）のテスト
python -m app --dev                # 開発サーバ
python -m importer --list          # 科目A の取り込み対象の回を表示
python -m importer                 # 科目A の問題取り込み（IPA PDF）
python -m importer.kamoku_b        # 科目B の取り込み（書籍付録は --src で PDF フォルダを指定）
python -m tools.pack               # スマホ単体版用のデータパックを作成（dist/）
python -m tools.build_site         # GitHub Pages 用サイト fe/ を生成（権利チェックあり）
```
