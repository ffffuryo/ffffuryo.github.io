# FE Study — 基本情報技術者試験 科目A 学習アプリ

通学中にスマホで 5〜10 分ずつ解く、自分専用の FE（基本情報技術者試験）科目A 対策アプリです。
Python（Flask）+ SQLite で自宅 PC / Raspberry Pi に置き、Tailscale 経由でスマホからアクセスします。

## 特長
- **1 タップで学習開始**（既定 8 問 ≒ 8 分）。途中で閉じても「続きから」で再開。
- **オートセーブ**: 回答は即保存、経過時間も 5 秒毎に保存。電波が切れても回答は端末に溜めて復帰時に送信。
- **解いた問題を記録**し、出題は「前回不正解 → 未出題（苦手分野優先）→ 時間がかかった問題 → 習得済み」の順に配分。
- **解答時間の記録と分析**: 平均・中央値・目標（90 秒）超過率、分野別平均時間、計算/非計算、時間帯別正答率、日別推移、遅かった問題。
- **分野別の成績一覧**: シラバス Ver.9.2 の 3 系統 23 中分類ごとに正答率・学習済数・平均時間。
- **計算問題を含める/含めない** の設定。
- **模擬試験**: 令和5〜8年度の公開問題（各 20 問）は模試専用（学習モードには出ない）。制限時間つき、終了まで正誤非表示。
- 目に優しい配色（ライト/ダーク自動）、文字サイズ 4 段階、ホーム画面に追加可能、電波がなくても起動可能（Service Worker）。

## 問題データ
| 区分 | 回 | 問数 | 用途 |
|---|---|---|---|
| 旧午前（平成21年春〜令和元年秋） | 22 回 | 1,760 | 学習 |
| 科目A免除試験（令和2〜4年度） | 3 回 | 240 | 学習 |
| 科目A サンプル問題 | 1 | 60 | 学習 |
| 公開問題 科目A（令和5〜8年度） | 4 回 | 80 | **模試専用** |

- 問題は **IPA 公式の公開問題 PDF** から取り込みます（IPA は許諾・使用料不要と明記。出典を各問題に表示）。
- 平成21年〜令和4年の PDF は**スキャン画像**のため、これらの問題は「問題の切り抜き画像 + ア〜エのボタン」で出題します（正解は解答例 PDF から取得し全件照合済み）。
  - 画像問題の中分類はシラバス順・解答例の分野列からの推定（目視で約 7〜8 割一致）。
  - 画像問題は**計算問題の判定ができない**ため、「計算問題を含めない」は文字データのある問題にのみ効きます。
    tesseract（日本語）を入れて取り込み直すと、OCR テキストで分類・計算判定が改善されます:
    `sudo apt-get install -y tesseract-ocr tesseract-ocr-jpn && python -m importer --offline`
- 解説は **過去問道場（fe-siken.com）** へのリンクで参照します（サイト内容の転載・スクレイピングはしません）。

## セットアップ
```bash
bash scripts/setup.sh      # venv 作成・依存インストール・IPA から問題取り込み（初回 数分）
bash scripts/run.sh        # http://127.0.0.1:8000/
```
スマホからの利用は [docs/DEPLOY_TAILSCALE.md](docs/DEPLOY_TAILSCALE.md)（`tailscale serve --bg 8000`）。

## 開発
```bash
python -m pytest -q tests          # テスト
python -m app --dev                # 開発サーバ
python -m importer --list          # 取り込み対象の回を表示
```
